| 任务编号 | 所属计划书 | 任务简称 |
|---|---|---|
| DP-A1 | DP | 定义 Package JSON Schema（pydantic 模型 + JSON Schema） |
| DP-A2 | DP | knowledge_packages 幂等迁移表 |
| DP-A3 | DP | Package 仓储层 |

| AC-P3-2 | AC | Workflow Graph 可视化（可选并入本批，独立可先行） |

**批次内建议执行顺序**
1. `DP-A1`（契约先行定稿，全局关键路径）→ `DP-A2` → `DP-A3`（落表 + 仓储）

1. `knowledge_packages` 建表成功且可重复执行（含手动 `psql -f`）
