# News Intelligence Module 设计规范

## 1. 定位

在 AI Investment Research Platform
中，新闻模块不应该设计成简单爬虫，而应该作为：

> News Intelligence Pipeline（新闻智能管线）

目标：

    全球信息
    → 新闻事件
    → 实体识别
    → 事实抽取
    → 知识图谱
    → Agent 推理
    → 投资研究报告

# 5. Provider Registry

新闻源不要写死。

使用配置注册：

    registry/

    └── news_sources.yaml

示例：

``` yaml
sources:

  - id: reuters

    type: rss

    category:
      - macro
      - geopolitics

    priority: high


  - id: eastmoney

    type: crawler

    market:
      - CN

    category:
      - stock
      - company
```

优点：

-   增加新闻源无需修改代码
-   支持动态启停
-   支持优先级调度

# 8. 新闻去重

大量新闻存在重复报道。

采用两级策略：

## 第一层

标题规则：

    title similarity

## 第二层

Embedding：

    Qwen3-Embedding-4B

            |

          Qdrant

            |

     similarity > threshold

            |

     duplicate

# 9. Entity Extraction

新闻不能只保存文本。

需要抽取：

    Company

    Person

    Country

    Industry

    Product

    Commodity

    Policy

例如：

新闻：

    NVIDIA announces partnership with TSMC

转换：

    NVIDIA
     |
     partnership
     |
    TSMC

形成实体关系。

# 18. 核心设计原则

新闻模块最终输出不是文章，而是：

    Fact

    +

    Entity

    +

    Relation

    +

    Event

    +

    Impact

新闻模块应该作为：

    Knowledge Layer 前端入口

    而不是

    简单新闻搜索系统

它与：

-   Knowledge Ingestion Agent
-   Knowledge MCP Server
-   Research Agent

共同组成投资研究智能系统。
