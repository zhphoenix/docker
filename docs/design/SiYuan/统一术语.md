# SiYuan 知识体系统一术语规范

> **权威来源**：本文件是 SiYuan 相关设计文档的术语权威参考。
> 所有设计文档、Agent 注册、接口文档和代码实现中的术语应以本文件为准。
>
> **上位权威**：Agent/Service 命名以 `specs/agent-registry.yaml` 为准；
> 类型枚举以 `specs/ontology.yaml` 为准。

## 一、统一术语表

### 1.1 核心概念

| 推荐名称 | 中文说明 | 所属组件/存储 | 定义 | 推荐写法 | 不建议写法 | 备注 |
|----------|---------|-------------|------|---------|-----------|------|
| Knowledge Object | 知识对象 | PostgreSQL | 平台统一知识模型的实例（Company、Event、Fact、Document 等） | `Knowledge Object` | Knowledge Item, Knowledge Entity, 知识条目 | 是 Knowledge Schema 的具体实例 |
| Knowledge Schema | 知识模型 | 规范层 | 平台统一知识模型定义（类型、字段、关系的规范） | `Knowledge Schema` | Knowledge Model, Data Model | 定义在 `specs/ontology.yaml` |
| Knowledge Database | 长期结构化知识库 | PostgreSQL | 经审核的可信知识持久化存储，Source of Truth | `Knowledge Database` | Knowledge Store, 知识库 | 特指 PostgreSQL 中的结构化事实存储 |
| Knowledge Graph | 知识图谱 | Apache AGE | 实体关系图结构，仅负责图查询（Cypher） | `Knowledge Graph` | Graph DB, 关系数据库 | Apache AGE 是存储引擎，Knowledge Graph 是逻辑概念 |
| Vector Index | 语义检索索引 | Qdrant | 向量化语义检索能力 | `Vector Index` | Vector DB, Vector Store, 向量数据库 | Qdrant 是存储引擎，Vector Index 是逻辑概念 |
| Knowledge Workspace | 知识工作台 | SiYuan | 人工浏览、审核、编辑、研究记录的交互界面 | `Knowledge Workspace` | Knowledge Human Interface, Human Knowledge UI, Human Knowledge Layer, 知识界面 | SiYuan 不是数据库，不是事实源 |
| Knowledge Rendering Engine | 知识渲染引擎 | 独立服务 | 将 Knowledge Object 通过模板渲染为可阅读页面的独立模块 | `Knowledge Rendering Engine` | Knowledge Rendering Pipeline, Page Generator, 页面生成器 | 独立于 MCP Server |
| Knowledge Platform | 知识平台 | 整体系统 | 上述所有组件组成的完整知识平台 | `Knowledge Platform` | AI Knowledge Operating System, Knowledge OS | 避免营销化命名 |

| 设计文档中的名称 | 规范名称 | 说明 |

- ~~Knowledge Writing Agent~~（写入由 Knowledge Ingestion Agent 的 merger 节点完成）

## 五、修订原则（红线）

以下原则在任何修订中不得违反：

1. **PostgreSQL 是唯一结构化事实源（Source of Truth）**，SiYuan 不是。
2. **Apache AGE 负责知识图谱查询**，SiYuan 不维护图谱。
3. **Qdrant 负责语义检索**，搜索不依赖 SiYuan 内置搜索。
4. **MinIO 负责文档存储**，PostgreSQL 仅存元数据引用。
5. **SiYuan 仅是知识工作台（Knowledge Workspace）**，不能被称为"知识数据库"、"最终知识库"或"唯一事实源"。
6. **所有对 SiYuan 的访问通过 Knowledge MCP Server（统一知识访问层）完成**，Agent 不直接调用 SiYuan API。
7. **页面生成由 Knowledge Rendering Engine 通过模板渲染驱动**，LLM 不直接拼接 Markdown。
8. **Agent 命名以 `specs/agent-registry.yaml` 为唯一权威**，不得随意创造新 Agent 名称。
9. **类型枚举以 `specs/ontology.yaml` 为唯一权威**，文档中出现的类型列表必须与之对齐。
