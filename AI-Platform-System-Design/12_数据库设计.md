# 数据库设计

## 一、定位

PostgreSQL 作为**业务真相源**，保存结构化业务数据。

**三大存储职责**：
- **PostgreSQL**：保存"事实数据" — 股票行情、公司信息、Agent 任务、文档处理状态
- **Qdrant**：保存"理解后的知识" — 文档 Chunk 的 Embedding 向量
- **MinIO**：保存"原始文件" — PDF、Markdown、图片、数据集

---

## 二、数据库规划

| 数据库 | 用途 |
|--------|------|
| `ai` | 业务数据（文档状态、公司信息、研究任务） |
| `langgraph` | LangGraph Checkpoint（Agent 状态持久化） |

## 三、表结构

> **完整规范见 [24_数据底座规范](24_数据底座规范.md) 第四章。**

### 3.1 documents 表（文档处理状态）

记录整个文档的处理状态，与 MinIO 中的 metadata.json 对应。

```sql
CREATE TABLE IF NOT EXISTS documents (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    market            VARCHAR(10) NOT NULL,
    symbol            VARCHAR(20) NOT NULL,
    year              INTEGER NOT NULL,
    document_type     VARCHAR(50) NOT NULL,
    title             VARCHAR(500),
    source_bucket     VARCHAR(50) DEFAULT 'documents',
    source_path       TEXT,
    mime_type         VARCHAR(100),
    language          VARCHAR(10),
    pages             INTEGER,
    author            VARCHAR(200),
    hash              VARCHAR(128),
    parser            VARCHAR(50),
    parser_version    VARCHAR(20),
    chunk_strategy    VARCHAR(50),
    chunk_version     VARCHAR(20),
    embedding_model   VARCHAR(50),
    embedding_version VARCHAR(20),
    chunk_count       INTEGER DEFAULT 0,
    status            VARCHAR(20) DEFAULT 'pending',
    metadata          JSONB DEFAULT '{}',
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    updated_at        TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(market, symbol, year, document_type)
);

CREATE INDEX idx_documents_status ON documents(status);
CREATE INDEX idx_documents_symbol_year ON documents(symbol, year);
CREATE INDEX idx_documents_metadata ON documents USING gin(metadata);
```

**状态流转**：
```
pending → parsed → embedded → completed
```

### 3.2 chunks 表（文本块）

真正 RAG 查询使用。不保存向量（向量在 Qdrant），只保存 `qdrant_point_id`。

```sql
CREATE TABLE IF NOT EXISTS chunks (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    document_id       UUID REFERENCES documents(id),
    chunk_index       INTEGER NOT NULL,
    content           TEXT NOT NULL,
    page_start        INTEGER,
    page_end          INTEGER,
    heading           VARCHAR(500),
    token_count       INTEGER,
    collection_name   VARCHAR(50),
    qdrant_point_id   UUID,
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    UNIQUE(document_id, chunk_index)
);
```

### 3.3 tasks 表（Agent 工作流任务）

```sql
CREATE TABLE IF NOT EXISTS tasks (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    document_id       UUID REFERENCES documents(id),
    task_type         VARCHAR(50) NOT NULL,
    status            VARCHAR(20) DEFAULT 'pending',
    priority          INTEGER DEFAULT 0,
    start_time        TIMESTAMPTZ,
    end_time          TIMESTAMPTZ,
    error             TEXT,
    result            JSONB DEFAULT '{}',
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    updated_at        TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.4 agents 表（Agent 配置）

```sql
CREATE TABLE IF NOT EXISTS agents (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name              VARCHAR(100) NOT NULL UNIQUE,
    description       TEXT,
    prompt_template   TEXT,
    model             VARCHAR(100),
    temperature       FLOAT DEFAULT 0.7,
    tools             JSONB DEFAULT '[]',
    config            JSONB DEFAULT '{}',
    is_active         BOOLEAN DEFAULT true,
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    updated_at        TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.5 collections 表（Qdrant Collection 管理）

```sql
CREATE TABLE IF NOT EXISTS collections (
    id                UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    name              VARCHAR(50) NOT NULL UNIQUE,
    description       TEXT,
    vector_size       INTEGER NOT NULL,
    distance          VARCHAR(20) DEFAULT 'Cosine',
    domain            VARCHAR(50),
    document_count    INTEGER DEFAULT 0,
    chunk_count       INTEGER DEFAULT 0,
    config            JSONB DEFAULT '{}',
    created_at        TIMESTAMPTZ DEFAULT NOW(),
    updated_at        TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.6 companies 表（公司信息）

```sql
CREATE TABLE IF NOT EXISTS companies (
    code            VARCHAR(20) PRIMARY KEY,    -- 公司代码：600519
    name            VARCHAR(200) NOT NULL,      -- 公司名称：贵州茅台
    market          VARCHAR(10) NOT NULL,       -- 市场：cn
    industry        VARCHAR(100),               -- 行业：白酒
    market_cap      BIGINT,                     -- 市值
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);
```

### 3.7 research_tasks 表（研究任务，Agent 预留）

```sql
CREATE TABLE IF NOT EXISTS research_tasks (
    id              SERIAL PRIMARY KEY,
    symbol          VARCHAR(20) REFERENCES companies(code),
    question        TEXT NOT NULL,              -- 研究问题
    status          VARCHAR(20) DEFAULT 'pending',  -- pending/running/completed/failed
    result          JSONB,                      -- 研究结果
    created_at      TIMESTAMPTZ DEFAULT NOW(),
    updated_at      TIMESTAMPTZ DEFAULT NOW()
);
```

## 四、扩展支持

### 4.1 pgvector

已启用 `pgvector` 扩展，支持在 PostgreSQL 中存储向量（备选方案）：

```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### 4.2 JSONB

`documents.metadata` 使用 JSONB 类型，支持灵活的元数据扩展：

```json
{
    "source": "上海证券交易所",
    "publish_date": "2026-03-30",
    "language": "zh",
    "ocr": false
}
```

## 六、注意事项

- **WSL2 NTFS 挂载盘不支持 chmod**，PostgreSQL 必须使用 named volume
- **MinIO 是文件真相源**，PostgreSQL 只保存 Key 引用，不保存文件内容
- **documents 表与 metadata.json 对应**，统一管理文档处理状态和版本
