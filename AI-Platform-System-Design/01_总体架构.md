# 总体架构

## 一、系统目标

搭建一个**完全离线、本地部署**的 AI 投研平台，核心处理上市公司年报及各类研究资料。

核心能力链路：

```
文档解析 → 向量化 → RAG 检索 → Agent 推理 → 知识沉淀
```

系统定义为"本地 AI 操作系统"，运行在 Windows 11 + WSL2 + Docker Desktop 环境，所有服务本地化部署，数据完全自控。

## 四、请求链路

```
用户提问
    │
    ▼
Open WebUI (:3000)
    │  HTTP POST /v1/chat/completions
    ▼
FastAPI (:8100)
    │  路由到 Agent Dispatcher
    ▼
Agent Dispatcher
    │  选择 Agent（Research / Knowledge / Chat）
    ▼
LangGraph Workflow
    │
    ├── Planner Node      → 生成执行计划
    ├── Retrieve Node      → Embedding + Qdrant 检索
    ├── Rerank Node        → Reranker 重排序
    ├── Reason Node        → LLM 推理
    ├── Reflect Node       → 检查答案质量
    ├── Write Vault Node   → 研究报告/结论写入 Obsidian
    └── Finish Node        → 输出最终结果
    │
    ▼
流式返回 → Open WebUI → 用户
```

### 知识闭环链路

```
Agent 写入报告 → Obsidian Vault → 投资人编辑/标注
                                       │
                        Agent 读取投资人笔记 ←┘
```

## 四、设计原则

| 原则 | 说明 |
|------|------|
| API 与 Workflow 解耦 | FastAPI 只负责 HTTP 协议，不包含业务逻辑 |
| Workflow 与 Tool 解耦 | LangGraph Graph 只编排流程，不直接访问基础设施 |
| Node 单一职责 | 每个 Node 只负责一件事，仅修改 State |
| Tool 只访问基础设施 | Tool 封装外部服务调用，不包含业务逻辑 |
| Prompt 独立管理 | 所有 Prompt 独立文件，统一加载 |
| 完全离线 | 不依赖 LangSmith、不需要官方 LangGraph Server、不需要许可证 |
| 数据完全自控 | 四大存储职责清晰：PostgreSQL（业务真相源）、Qdrant（语义检索索引）、MinIO（文件真相源）、Obsidian（投资思想库） |
| Vault 即共享知识空间 | Obsidian Vault 是 Agent 间异步协作的媒介：Research Agent 写入报告，Investment Agent 读取引用，Knowledge Agent 维护索引 |

## 五、演进路线

| 阶段 | 重点 | LangGraph 角色 |
|------|------|---------------|
| 第一阶段 | 本地 RAG（Docling + PostgreSQL + Qdrant + Embedding + Reranker） | 暂不引入 |
| 第二阶段 | 单 Agent（Research Agent） | 开始引入 |
| 第三阶段 | 多 Agent（投资、学习、知识管理） | 成为系统核心 |

建议路径：先把文档处理和 RAG 打牢 → 完成一个稳定单 Agent → 需要"规划、分支、状态管理"时再引入 LangGraph。

---

## 六、四大存储职责边界

| 存储 | 职责 | 保存什么 | 不保存什么 |
|------|------|---------|----------|
| **PostgreSQL** | 业务真相源 | 事实数据：股票行情、公司信息、Agent 任务、文档处理状态 | 向量、文件 |
| **Qdrant** | 语义检索索引 | 理解后的知识：Chunk Embedding 向量 + 元数据 | 原始文件、精确数值 |
| **MinIO** | 文件真相源 | 原始文件：PDF、Markdown、图片、数据集 | 向量、关系型数据 |
| **Obsidian** | 投资思想库 | 投资思想：研究结论、行业认知、投资逻辑、关联关系 | 全部年报原文、向量 |
