# 部署流程

## 一、定位

按基础设施 → Agent → Open WebUI 顺序部署。

---

## 二、部署步骤

### 2.1 环境准备

```bash
# 1. 确认 WSL2 + Docker Desktop 运行正常
wsl --status
docker --version

# 2. 创建 Docker 网络
docker network create ai-platform

# 3. 确认 GPU 驱动
nvidia-smi
```

### 2.2 部署基础设施

```bash
# 按顺序启动，每个服务确认健康后再启动下一个

# PostgreSQL（业务数据库 + Checkpoint）
cd /mnt/e/docker/postgres
docker compose up -d
docker compose ps  # 确认 healthy

# Qdrant（向量数据库）
cd /mnt/e/docker/qdrant
docker compose up -d

# MinIO（对象存储）
cd /mnt/e/docker/minio
docker compose up -d

# 初始化 MinIO Buckets（首次部署）
docker exec minio mc alias set local http://localhost:9000 minioadmin minioadmin
docker exec minio mc mb local/documents
docker exec minio mc mb local/knowledge
docker exec minio mc mb local/datasets
docker exec minio mc mb local/artifacts
docker exec minio mc mb local/staging
```

### 2.3 部署模型服务

```bash
# Embedding（文本向量化）
cd /mnt/e/docker/embedding
docker compose up -d
# 等待模型加载（约 2 分钟）

# Reranker（重排序）
cd /mnt/e/docker/reranker
docker compose up -d

# Docling（文档解析）
cd /mnt/e/docker/docling
docker compose up -d

# LLM（大语言模型）
# 假设 llama.cpp 已在其他目录部署
```

### 2.4 部署 Agent 服务

```bash
# LangGraph Agent（FastAPI）
cd /mnt/e/docker/langgraph
docker compose up -d --build
```

### 2.5 部署前端

```bash
# Open WebUI
cd /mnt/e/docker/openwebui
docker compose up -d
```

### 2.6 配置 Obsidian（Windows 侧）

```bash
# 1. 确认 Obsidian 已运行并打开 Vault
# 2. 确认 Local REST API 插件已启用
# 3. 验证 MCP 连接
curl -k https://localhost:27124/api/v1/search?q=test

# 4. 验证 Agent 容器可访问
docker exec langgraph curl -k https://host.docker.internal:27124/api/v1/search?q=test
```

## 三、验证部署

```bash
# 检查所有容器状态
docker ps --format "table {{.Names}}\t{{.Status}}\t{{.Ports}}"

# 验证各服务健康
curl http://localhost:5432  # PostgreSQL（应连接失败但服务在运行）
curl http://localhost:6333/healthz  # Qdrant
curl http://localhost:9000/minio/health/live  # MinIO
curl http://localhost:8001/health  # Embedding
curl http://localhost:8002/health  # Reranker
curl http://localhost:5001/health  # Docling
curl http://localhost:8080/health  # LLM
curl http://localhost:8100/health  # Agent Service
curl http://localhost:3000  # Open WebUI
curl -k https://localhost:27124/api/v1/search?q=test  # Obsidian MCP
```

---

## 四、升级流程

```bash
# 升级某个服务
cd /mnt/e/docker/<service>
docker compose pull
docker compose up -d

# 升级所有服务
for dir in postgres qdrant minio embedding reranker docling openwebui; do
    cd /mnt/e/docker/$dir
    docker compose pull
    docker compose up -d
done
```

---

## 五、回滚

```bash
# 回滚到上一个版本
docker compose down
docker compose up -d  # 使用已拉取的旧镜像
```

| 服务 | 数据位置 | 备份方式 |

| MinIO | `/mnt/d/minio/data/` | 目录拷贝 |
| Open WebUI | named volume `open-webui` | 目录拷贝 |
| Obsidian Vault | `E:\Knowledge\Vault\` | 目录拷贝（完全本地化） |
