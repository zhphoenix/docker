# 测试规范

## 一、定位

三层测试体系：单元测试、集成测试、API 测试。

---

## 二、测试层级

| 层级 | 目录 | 范围 | 工具 |
|------|------|------|------|
| 单元测试 | `tests/unit/` | Node、Tool、Prompt Loader | pytest |
| 集成测试 | `tests/integration/` | Graph 完整流程 | pytest + Docker |
| API 测试 | `tests/api/` | HTTP 端点 | httpx + pytest |

---

## 三、单元测试

### 3.1 Node 测试

```python
# tests/unit/test_planner.py
import pytest
from nodes.planner import planner

@pytest.mark.asyncio
async def test_planner_generates_plan():
    state = {
        "question": "分析宁德时代",
        "plan": {},
        "documents": [],
        "messages": [],
        "tool_results": {},
        "answer": "",
        "reflect": {},
        "metadata": {}
    }
    result = await planner(state)
    assert "plan" in result
    assert "steps" in result["plan"]
```

### 3.2 Tool 测试（Mock）

```python
# tests/unit/test_qdrant_tool.py
import pytest
from unittest.mock import AsyncMock
from tools.qdrant import QdrantTool

@pytest.mark.asyncio
async def test_qdrant_search():
    tool = QdrantTool()
    tool.client = AsyncMock()
    tool.client.search.return_value = [
        {"id": "1", "score": 0.9, "payload": {"content": "test"}}
    ]
    results = await tool.search("documents_cn", [0.1] * 2560)
    assert len(results) == 1
```

## 四、集成测试

### 4.1 Graph 完整流程

```python
# tests/integration/test_graph.py
import pytest
from graph.builder import build_graph

@pytest.mark.asyncio
async def test_full_graph():
    graph = build_graph()
    result = await graph.ainvoke({
        "question": "分析贵州茅台2025年报",
        "messages": [],
        "plan": {},
        "documents": [],
        "tool_results": {},
        "answer": "",
        "reflect": {},
        "metadata": {}
    })
    assert result["answer"] != ""
```

## 五、API 测试

```python
# tests/api/test_chat.py
import pytest
from httpx import AsyncClient
from app.main import app

@pytest.mark.asyncio
async def test_chat_completions():
    async with AsyncClient(app=app, base_url="http://test") as client:
        response = await client.post("/v1/chat/completions", json={
            "model": "qwen3",
            "messages": [{"role": "user", "content": "你好"}],
            "stream": False
        })
        assert response.status_code == 200
        assert "choices" in response.json()
```

## 六、运行测试

```bash
# 运行所有测试
pytest tests/

# 运行单元测试
pytest tests/unit/

# 运行集成测试（需要 Docker 服务）
pytest tests/integration/

# 运行 API 测试
pytest tests/api/
```

## 七、测试原则

| 原则 | 说明 |
|------|------|
| Node 可独立测试 | 通过 Mock Tool 隔离外部依赖 |
| Tool 可 Mock | 接口统一，易于 Mock |
| 集成测试需要真实服务 | 使用 Docker Compose 启动测试环境 |
| 测试数据独立 | 不依赖生产数据 |
