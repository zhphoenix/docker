# 配置管理

## 一、定位

使用 `.env` 与 Pydantic Settings 管理配置，集中管理所有环境变量。

---

## 二、配置文件结构

```text
/mnt/e/docker/
├── .env                    # 全局环境变量（不提交到版本控制）
├── .env.example            # 环境变量示例（提交到版本控制）
└── AI-Platform-System-Design/
    └── agent/
        └── config/
            └── settings.py # Pydantic Settings
```

## 四、Pydantic Settings

```python
from pydantic_settings import BaseSettings

class Settings(BaseSettings):
    # PostgreSQL
    POSTGRES_USER: str
    POSTGRES_PASSWORD: str
    POSTGRES_DB: str
    POSTGRES_HOST: str = "postgres"
    POSTGRES_PORT: int = 5432
    
    # Qdrant
    QDRANT_HOST: str = "qdrant"
    QDRANT_PORT: int = 6333
    
    # MinIO
    MINIO_ENDPOINT: str = "minio:9000"
    MINIO_ROOT_USER: str
    MINIO_ROOT_PASSWORD: str
    
    # LLM
    OPENAI_BASE_URL: str
    OPENAI_API_KEY: str
    MODEL_NAME: str = "qwen3"
    
    # Embedding
    EMBEDDING_URL: str = "http://embedding:8080/v1"
    
    # Reranker
    RERANKER_URL: str = "http://reranker:8080/v1"
    
    # Docling
    DOCLING_URL: str = "http://docling:5001"
    
    # Obsidian
    OBSIDIAN_URL: str = "https://host.docker.internal:27124"
    OBSIDIAN_API_KEY: str = ""
    
    class Config:
        env_file = ".env"
        env_file_encoding = "utf-8"

settings = Settings()
```

## 五、配置加载

Agent 服务通过 `env_file` 加载 `.env`：

```yaml
# compose.yml
services:
  langgraph:
    env_file:
      - ../.env
```

---

## 六、注意事项

| 注意 | 说明 |
|------|------|
| 分隔线注释 | `.env` 文件分隔线必须以 `#` 开头，不能用其他符号 |
| 不使用 export | 不要在 `.env` 中使用 `export` 前缀 |
| 敏感信息 | `.env` 不提交到版本控制，提供 `.env.example` 作为模板 |
| 默认值 | 非敏感配置可在 Settings 中设置默认值 |
| 云端切换 | 通过注释切换本地/云端 LLM |
