# 一、总体开发路线

整个 AI Platform 建议采用渐进式开发，而不是一开始就开发桌面版。

推荐路线：

```text
第一阶段
Web UI
↓

第二阶段
Web UI + 后端稳定

↓

第三阶段
Tauri 2 封装

↓

第四阶段
桌面平台优化
```

这样可以避免大量重复开发。

---

# 二、为什么先开发 Web UI

目前 AI Platform 的主要目标是：

- AI Agent
- LangGraph
- 工作流
- RAG
- 文档管理
- 数据分析
- 投资研究

这些都属于业务功能。

因此应优先开发：

```text
业务功能
↑
高优先级

桌面功能
↑
后期增加
```

因为：

Web UI 与桌面版共用同一套界面代码。

# 四、Web UI 与 Tauri 的关系

很多人误认为：

```
Web UI
↓

升级为

Tauri
```

实际上：

```
React
↓

Web UI

↓

浏览器
```

只是运行方式。

以后变成：

```
React
↓

Web UI

↓

Tauri

↓

Windows/macOS/Linux
```

因此：

> **Tauri 只是运行容器（Container），不是 UI 框架。**

# 九、为什么采用该路线

采用 **"Web UI 优先、Tauri 后置"** 的开发策略具有以下优势：

1. **开发效率高**
   - 专注业务逻辑，不受桌面平台限制。

2. **代码复用率高**
   - Web 版与桌面版共享绝大部分 React 前端代码。

3. **后端保持稳定**
   - FastAPI、LangGraph、Docker、数据库等无需因桌面化而重构。

4. **逐步扩展能力**
   - 在业务成熟后，再通过 Tauri 增加系统托盘、自动更新、本地文件访问、快捷键等桌面能力。

5. **长期维护成本低**
   - 一套核心代码可同时支持浏览器和原生桌面应用，便于持续迭代。

# 附录：Specification-Driven 开发方法论

> 本节内容整理自早期设计讨论，描述 AI Platform 未来引入 Specification Agent 的方法论方向。

## A.1 核心理念

Specification 是 AI 时代的 UML —— 将自然语言需求转化为结构化规格，再由 Coding Agent 执行。

推荐流程：

```text
用户
  ↓
Specification Agent（LLM 起草）
  ↓
Draft Specification（草稿）
  ↓
Architecture Agent（架构合规检查）
  ↓
Review Agent（完整性检查）
  ↓
人工批准（可选）
  ↓
Official Specification
  ↓
Coding Agent
```

关键区别：LLM 负责**起草**，不是直接决定。

## A.2 多 Agent 协作审查

| Agent | 职责 |
|-------|------|
| Requirement Agent | 理解需求，提取业务目标 |
| Specification Agent | 生成规格草案 |
| Architecture Agent | 检查是否符合平台架构（如存储只能用 PostgreSQL，拒绝 sqlite） |
| Security Agent | 检查安全策略合规性 |
| Test Agent | 根据规格生成验收测试，反向验证规格可测试性 |
| Review Agent | 综合各方意见，输出最终版本 |

## A.3 Specification Agent 定位

Specification Agent 应做成"收敛器（Consolidator）"，综合以下信息来源：

- 用户的自然语言需求
- `policies/`（长期工程规则）
- `registry/`（已有 Provider、Workflow、Agent）
- 历史 `specs/`（避免重复定义）
- 当前 `tasks/`（开发任务）

生成的 Specification 是符合平台标准、可复用、可验证的规格草案，而非一次性文件。

## A.4 示例

用户输入："增加 Firecrawl Provider"

Specification Agent 输出：

```yaml
provider:
  name: firecrawl
category: web
input: url
output: markdown
quality:
  coverage: 95
acceptance:
  retry: true
performance:
  timeout: 60
```

整个 AI Platform 围绕这份 Specification 进行开发、测试和验收。
