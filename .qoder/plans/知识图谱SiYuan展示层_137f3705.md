# 知识图谱模块（SiYuan 关系图展示层）

## 概述
用户已确认：知识图谱展示载体采用 **SiYuan 关系图**（不引入前端图库），前端 `/knowledge` 图谱 Tab 采用 **工作台+跳转** 形态。核心思路：后端渲染实体文档时注入指向邻居实体的 SiYuan 块引用链接（`[[实体名]]`），SiYuan 内置关系图即可基于这些链接自动生成关联图谱。数据源复用现有 `core.relations` 关系数据。

## 设计红线
- **PG 为唯一数据源（SoT）**，SiYuan 仅作展示层。
- 修改只读 PG、只写 SiYuan（渲染层），不写入任何业务状态。

## 后端改动（mcp-knowledge/server）

### 1. 邻居渲染数据查询 — `storage/postgres.py`
新增异步方法 `get_entity_neighbors_for_render(entity_id, limit=50)`：
- 返回起实体一跳邻居的完整信息：`id, canonical_name, entity_type, properties(ticker), relation_type`。
- 用 `find_related_companies(entity_id, depth=1)` 取一跳关系（source/target/relation_type），再 JOIN `core.entities` 补齐邻居的名称/类型/属性。
- 与现有 `find_related_companies` 复用无向扩展逻辑，避免重复 CTE。

### 2. 模板上下文注入 — `adapters/siyuan/mapper.py`
- 新增 `neighbor_to_link(neighbor) -> str`：生成 SiYuan 块引用链接文本 `[[{canonical_name}]]`（基于文档标题，模板首行 `# {{ name }}`）。
- 扩展 `entity_to_template_context`：新增可选参数 `neighbors: list[dict]`，注入 `related_entities`（列表，含 `name`(链接文本) 与 `relation_type`）到返回 context。

### 3. 模板新增"相关实体" Section — `adapters/siyuan/templates/`
- `company.md` / `industry.md` / `event.md` 末尾新增：
  ```
  ## 相关实体
  {% for r in related_entities %}- [[{{ r.name }}]]（{{ r.relation_type }}）
  {% else %}_（暂无关联）_{% endfor %}
  ```
- 无邻居时渲染占位 `_（暂无关联）_`，避免空模板报错。

### 4. 增量同步接入 — `adapters/siyuan/sync.py`
- `sync_entity` 中：在渲染前调用 `get_entity_neighbors_for_render(entity_id)`，将结果传入 `entity_to_template_context(..., neighbors=...)`。
- 保持现有增量 diff、幂等 upsert、sync 元数据更新逻辑不变。

### 5. 全量重建脚本 — `scripts/rebuild_siyuan_graph.py`
- 遍历所有 `status='active'` 实体，强制重建（绕过版本判断直接 upsert），确保**已有的**实体文档也包含链接、关系图立即可用。
- 打印每实体 path/action 结果汇总；支持 `--limit` 抽样。

## 前端改动（frontend）

### 6. 图谱服务与配置 — `src/services/knowledge.ts`
- 新增常量 `SIYUAN_URL = import.meta.env.VITE_SIYUAN_URL || 'http://localhost:6806'`。
- 新增 `SIYUAN_GRAPH_GUIDE` 常量（跳转说明文案）。
- 复用已有的 `fetchKnowledgeStats`（entities/facts 统计）、`fetchEntities`（实体列表）。

### 7. 图谱工作台组件 — 新建 `src/components/knowledge/GraphWorkspace.tsx`
- 顶部：知识图谱统计卡片（实体数、关系数、事实数，来自 `fetchKnowledgeStats`）。
- 中部：实体列表（复用 `fetchEntities`，展示名称/类型/置信度）。
- 底部操作区：**"打开 SiYuan 关系图"** 按钮（`window.open(SIYUAN_URL, '_blank')`）+ 使用说明（提示在 SiYuan 顶部工具栏打开"关系图"查看 实体间关联）。
- 与服务端一致的 `useQuery` 缓存隔离，加载/错误态处理。

### 8. 启用知识图谱 Tab — `src/app/pages/KnowledgePage.tsx`
- 移除 42-47 行 `disabled` 与 `Soon` 徽章，`<TabsTrigger value="graph">`。
- 新增 `<TabsContent value="graph"><GraphWorkspace /></TabsContent>`。

## 配置
- `frontend/.env.example` 补充 `VITE_SIYUAN_URL=http://localhost:6806`（前端跳转 SiYuan 地址）。

## 验证
1. 后端：`py_compile` 检查 `storage/postgres.py`、`mapper.py`、`sync.py`、`rebuild_siyuan_graph.py`；无 lint 错误。
2. 运行 `rebuild_siyuan_graph.py`（抽样）确认实体文档含 `[[链接]]`。
3. 用 SiYuan API 抽查某实体文档内容，确认"相关实体" Section 已渲染、链接格式正确。
4. 前端：确认 `/knowledge` 图谱 Tab 可点击、工作台渲染正常、跳转按钮可用（`npm run build` 或 dev 验证）。
5. 确认 SiYuan 关系图能显示实体关联（若 `[[name]]` 未被解析为引用，回退为按文档 ID 生成块引用，见风险）。

## 假设与风险
- **SiYuan 块引用解析**：`[[name]]` 在 API 写入的 Markdown 中是否被解析为文档引用取决于 SiYuan 版本。若未解析，回退方案：渲染前用 `getDocByPath` 查邻居文档 ID，生成 `[[name#ID]]` 或块引用 ID 语法。
- **重名实体**：`canonical_name` 可能不唯一，`[[name]]` 可能指向错误文档。回退方案同风险点（按文档 ID 引用）。
- 前端跳转 SiYuan 为浏览器直接导航，跨域不受 CORS 限制；SiYuan 认证由用户浏览器会话处理。
