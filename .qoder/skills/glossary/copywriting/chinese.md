# 中文文案规范

> 来源：`docs/design/术语统一规范.md` §7

## 语言分工

- 标题、按钮、空态、描述 → **使用中文**
- 枚举值、字段名 → **使用英文小写**（如 `pending`、`indexed`）
- 状态列展示 → **中文标签**（如「待处理」「已索引」），源值用小写英文

## 示例

| 场景 | 正确 | 错误 |
| --- | --- | --- |
| 页面标题 | 文档中心 | Document Center |
| 状态列 | 待处理 | Pending |
| 空态文案 | 暂无数据 | No data |
| 后端字段 | `status` | `Status` |

## 使用约束

- 面向用户的一切文案用中文，代码标识符用英文
- 禁止将英文枚举值直接作为 UI 展示文案
- 禁止将中文作为数据库字段名 / 枚举值
