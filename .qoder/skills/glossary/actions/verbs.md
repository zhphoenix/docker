# 操作动词中英对照规范

> 来源：`docs/design/术语统一规范.md` §5

## 动词对照表

| 中文 | 英文 |
| --- | --- |
| 查看 | Open |
| 重新处理 | Reprocess |
| 删除 | Delete |
| 重新向量化 | Re-embed |
| 查看图 | Graph |
| 查看分块 | Chunks |

## 使用约束

- 按钮功能名使用英文动词（如 `Open`、`Reprocess`）
- 按钮文案 / 提示语使用中文（如「查看」「重新处理」）
- 禁止自行发明同义动词（如 `View`、`Reindex`、`DeleteAll` 未在表中不得使用）
- 一个操作 → 一个动词，禁止混用
